# Lixel Panorama Tour — Krpano 1.19-pr16

## Структура папок

```
project/
├── krpano.js              ← ваш движок krpano (единственный файл)
├── panorama_tour.html    ← главная страница
├── app.js                 ← логика тура
├── tour_config.js         ← данные панорам (генерируется из CSV)
├── csv_to_krpano_config.py ← конвертер CSV → JS
├── hotspot_arrow.png      ← иконка стрелки (64×64 PNG)
├── panoramicImage/        ← JPEG-панорамы из Lixel Studio
│   ├── 1712345678.123456.jpg
│   ├── 1712345679.234567.jpg
│   └── ...
└── panoramicPoses.csv     ← координаты из Lixel Studio (источник)
```

## Запуск

### 1. Подготовьте данные
- Скопируйте JPEG-панорамы в папку `panoramicImage/`
- Скопируйте `panoramicPoses.csv` в корень проекта
- Положите `krpano.js` в корень
- Добавьте `hotspot_arrow.png` (любая стрелка 64×64 PNG)

### 2. Сгенерируйте tour_config.js
```bash
python csv_to_krpano_config.py
```

### 3. Запустите локальный сервер
krpano не работает по file:// — нужен веб-сервер:
```bash
python -m http.server 8080
```

### 4. Откройте в браузере
```
http://localhost:8080/panorama_tour.html
```

## Что работает

| Функция | Описание |
|---|---|
| Просмотр панорамы | Вращение, зум (мышь/тач) |
| Hotspots-стрелки | 5 ближайших панорам, клик = переход с blend |
| Мини-карта | Точки на плане, клик = открыть панораму |
| Список панорам | С расстояниями до текущей точки |
| Назад/Вперёд | История переходов / ближайшая панорама |
| Начальный YAW | Из кватерниона — камера смотрит в правильную сторону |
| Встроенный скин | Кнопки управления внизу (не нужен defaultskin.xml) |

## Технические детали

### krpano.js вместо tour.js
В krpano 1.19-pr16 файл движка может называться как угодно.
Главное — указать его в `<script src="krpano.js">` и вызвать `embedpano()`.
Параметр `swf: null` отключает Flash fallback (работает только HTML5).

### Встроенный скин
Скин (кнопки ← → ▲ ▼ + −) встроен прямо в генерируемый XML.
Не нужен внешний `defaultskin.xml` или `skin/` папка.

### Динамический XML
XML собирается в JS-функции `buildSceneXML()` для каждой панорамы:
- `<sphere url="panoramicImage/xxx.jpg">` — equirectangular JPEG
- `<hotspot>` для 5 ближайших с азимутом по координатам
- `<view hlookat="yaw">` — начальный угол из кватерниона
- Загрузка через `krpano.call("loadxml(..., BLEND(0.8))")`

### Формат panoramicPoses.csv
```
imgname x y z qw qx qy qz
1712345678.jpg 12.345 -45.678 1.523 0.8046 -0.000009 -0.000015 0.5938
```
Разделитель — пробел. Заголовок (первая строка) пропускается.
