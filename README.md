# Система интерактивных панорам (krpano + OpenLayers + Math.js)

Готовый фронтенд-шаблон для вывода виртуальных панорамных туров с интеграцией ГИС-карты, работающей по протоколу WMS (GeoServer).

## Структура проекта
* `index.html` — Разметка интерфейса.
* `style.css` — Стили оформления.
* `app.js` — Логика расчетов и интеграция системных событий.
* `projects.json` — База данных проектов и матриц 4x4.
* `tour.xml` — Конфигурация ядра плеера krpano.
